# Sorting Algorithm Visualizer

A python program that visualizes sorting aglorithms using Pygame. It shows how Bubble sort, insertion sort and seletion sort work. 

Features:
- Visualizes Bubble Sort, Insertion Sort and Selection Sort
- Controls to start, reset, speed and order
- Color-coded bars for tracking comaprisons and swaps

How to Run:
1. Clone the repository or download .py file
2. Install dependencies
- pip install pygame
3. Run the program
- python sorting_visualizer.py


Controls: 
R - Reset the list with new random values
SPACE - Start sorting
A - Set sorting to ascending order
D - Set sorting to descending order
B - Select Bubble Sort
I - Select Insertion Sort
S - Select Selection Sort
UP ARROW - Increase sorting speed
DOWN ARROW - Decrease sorting speed
